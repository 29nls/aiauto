# Jitbit Macro Recorder — Panduan Dragon Nest

Panduan setup macro recorder **offline** untuk farming repetitif di Dragon Nest.
Tidak perlu API key, tidak perlu internet, tidak ada rate limit — rekam sekali, jalan selamanya.

---

## 1. Persiapan Game

### Mode Tampilan

Jitbit "Relative to Window" **hanya bekerja** di mode **Windowed** atau **Borderless Window**.
Fullscreen Exclusive tidak didukung.

1. Buka Dragon Nest → **Settings (O)** → tab **Screen/Video**
2. Cari **Screen Mode** / **Window Mode**
3. Pilih: **Borderless Window** (direkomendasikan) atau **Windowed**
4. Resolusi: **1024 × 768** (ringan, konsisten, sama dengan capture region `dn_bot`)

> 💡 **Kenapa 1024×768?** Lebih ringan untuk farming lama, koordinat UI tidak berubah antar sesi, dan region capture `dn_bot` (8,31,1024,768) juga pakai resolusi ini.

---

## 2. Install Jitbit Macro Recorder

1. Download dari: https://www.jitbit.com/macro-recorder/
2. Install versi **free** (cukup untuk recording + playback + loop)
3. Buka aplikasi — tunggu sampai main window muncul

---

## 3. Setup Recording Mode

### Pilih "Relative to Window"

1. Di Jitbit, klik **New Macro** (Ctrl+N)
2. Klik tab **Settings** di panel macro
3. Di **Recording Mode**, pilih **"Relative to Window"**
4. Di **Target Window**, klik dropdown → pilih **"Insane Dragon Nest DX11"**

> Jika dropdown kosong: pastikan game SUDAH terbuka sebelum memilih. Kalau tetap tidak muncul, restart Jitbit.

### Atur Playback

| Setting | Nilai | Keterangan |
|---|---|---|
| **Playback Speed** | 1× (normal) | Jangan dipercepat — jeda jadi tidak akurat |
| **Repeat** | Centang, pilih **"Repeat indefinitely"** | Untuk farming nonstop |
| **Hotkey Start** | `Ctrl+Shift+F9` | Bebas, asal tidak bentrok dengan game |
| **Hotkey Stop** | `Ctrl+Shift+F10` | **Wajib diingat** — ini emergency stop |

## 4. Rekam Macro Farming Minotaur

### Urutan Langkah

Berikut sequence 1 loop farming Minotaur Nest:

| # | Aksi | Tipe | Detail | Jeda Setelah |
|---|---|---|---|---|
| 1 | Jalan ke portal | Keyboard | Tahan `W` 3-4 detik | `Sleep 1000 ms` |
| 2 | Klik portal | Mouse | Klik kiri di portal nest | `Sleep 4000 ms` (loading) |
| 3 | Klik Enter | Mouse | Klik `[729, 493]` di dialog konfirmasi | `Sleep 5000 ms` (loading dungeon) |
| 4 | Combat rotation | Keyboard | Skill 1 → 2 → 3 → 4 → 5 (sesuaikan job) | `Sleep 500 ms` antar skill |
| 5 | Ulangi combat | Keyboard | Loop combat ~2-5 menit sampai boss mati | — |
| 6 | Jalan ke loot | Keyboard | Tahan `W` 2 detik, lalu `F` untuk loot | `Sleep 2000 ms` |
| 7 | Keluar nest | Keyboard | `ESC` atau klik tombol keluar | `Sleep 5000 ms` (loading town) |
| 8 | Ulangi dari #1 | — | Loop kembali | — |

### Cara Merekam

1. Posisikan karakter di **town**, dekat portal nest
2. Klik **Record** (tombol merah) di Jitbit
3. **Fokus ke game** — lakukan semua langkah di atas secara manual
4. Klik **Stop** (kotak biru) setelah selesai 1 loop penuh
5. **Simpan macro** dengan nama `minotaur-farm.mcr`

### Edit Setelah Rekam

Setelah rekam, buka editor macro:

- **Hapus gerakan mouse yang tidak perlu** (mouse bergerak idle saat mikir)
- **Tambah jeda** di titik kritis (klik kanan aksi → **Insert Delay**)
- **Edit koordinat klik** kalau ada yang meleset (klik kanan → **Edit**)

---

## 5. Jeda (Sleep) yang Wajib

Tanpa jeda, macro bisa klik sebelum UI muncul → gagal total.

| Situasi | Jeda Minimum | Rekomendasi |
|---|---|---|
| Setelah klik dialog (Enter/Cancel) | 2000 ms | 3000 ms |
| Setelah loading screen (portal → dungeon) | 4000 ms | 5000 ms |
| Setelah loading screen (dungeon → town) | 4000 ms | 5000 ms |
| Antar skill dalam rotasi | 300 ms | 500 ms |
| Setelah tekan `F` (loot) | 1000 ms | 1500 ms |
| Setelah klik NPC/portal | 1000 ms | 2000 ms |

> 💡 **Rule of thumb**: kalau ragu, tambah jeda. Lebih baik lambat 1 detik daripada gagal 1 loop penuh.

## 6. Emergency Stop

### Hotkey Stop

- Default: `Ctrl+Shift+F10` (atau hotkey yang Anda set)
- **Harus dihafal** — ini satu-satunya cara berhenti kalau macro kacau
- Kalau mouse stuck di pojok kiri atas: gerakkan mouse ke tengah layar dulu, lalu tekan hotkey

### Cara Aman Tes

1. **Tes 1 loop dulu** — jangan langsung loop selamanya
2. **Awasi 2-3 loop pertama** — pastikan semua klik tepat
3. **Siapkan jari di hotkey stop** — terutama saat tes pertama
4. **Jangan alt-tab** saat macro jalan — window game harus di foreground

## 7. Troubleshooting

| Masalah | Penyebab | Solusi |
|---|---|---|
| Klik meleset / di luar game | Game di Fullscreen Exclusive | Ganti ke **Borderless Window** di game settings |
| Klik meleset padahal sudah Windowed | Koordinat absolute, bukan relative | Pastikan Recording Mode = **"Relative to Window"** + target = **"Insane Dragon Nest DX11"** |
| Macro berhenti di tengah | Loading lebih lama dari jeda | Tambah jeda setelah loading screen (4000 → 6000 ms) |
| Skill tidak keluar | Jeda antar skill terlalu pendek | Tambah jeda 500-800 ms antar skill |
| Dialog tidak terklik | Koordinat salah karena resolusi beda | Pastikan resolusi game = 1024×768. Kalau beda, cari ulang koordinat dengan screenshot |
| Macro jalan tapi game tidak merespons | Window game tidak fokus | Klik window game sebelum start macro. Jangan alt-tab. |
| Macro tidak bisa stop | Hotkey bentrok dengan aplikasi lain | Ganti hotkey di Jitbit Settings |
| Setelah berjam-jam, macro drift | Game lag / frame drop menumpuk | Restart macro setiap 30-60 menit, atau tambah jeda lebih panjang |

## 9. Perbandingan: dn_bot vs Jitbit

| | `dn_bot` (AI Vision) | Jitbit Macro |
|---|---|---|
| **Cara kerja** | Screenshot → Gemini API → klik | Rekam & putar ulang deterministik |
| **Ketergantungan** | Internet + API key + quota | Offline, tidak perlu apa pun |
| **Keandalan** | Rentan rate limit, thought_signature, quota habis | Sangat stabil — tidak pernah gagal |
| **Fleksibilitas** | Bisa adaptasi situasi tak terduga | Kaku — hanya replay persis rekaman |
| **Risiko utama** | API error di tengah sesi | Posisi karakter/UI geser → klik meleset |
| **Cocok untuk** | Eksplorasi, dynamic pathing | Farming repetitif rute tetap |
| **Setup** | `pip install`, `.env`, API key | Install Jitbit, rekam 1 loop |

## 10. Tips Lanjutan

### Gunakan Fitur "Wait for Image"

Jitbit punya fitur menunggu gambar tertentu muncul sebelum lanjut. Berguna untuk:

- **Tunggu dialog Enter muncul** sebelum klik tombol
- **Tunggu loading screen hilang** sebelum combat
- **Tunggu loot UI muncul** sebelum tekan F

Caranya: Insert → **Wait for Image** → crop area kecil (misal: tulisan "Enter" di dialog) → Jitbit akan pause sampai gambar itu muncul di layar.

### Split Macro per Fase

Daripada 1 macro panjang, buat beberapa macro kecil:

- `minotaur-enter.mcr` — town → portal → Enter dialog
- `minotaur-combat.mcr` — rotasi combat sampai boss mati
- `minotaur-loot-exit.mcr` — loot → keluar dungeon

Lalu gabungkan dengan fitur **Run Macro** di Jitbit untuk memanggil macro lain.

### Backup Macro

File `.mcr` adalah aset berharga — backup ke cloud/Flashdisk. Lebih baik lagi, catat urutan langkah di file teks supaya bisa direkam ulang kalau file corrupt.
